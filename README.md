# Medical Appointment Booking

## Project Description

Medical Appointment Booking is a website designed to help users find doctors and book medical appointments online.

## Project Features

- User Sign Up
- User Login
- Navigation Bar
- Doctor search
- Appointment booking
- Patient profile
- Doctor reviews
- Appointment notifications

## Project Structure

- Landing_Page - Website landing page
- Navbar - Navigation bar
- Sign_Up - User registration form
- Login - User login form

## Setup Instructions

1. Clone or fork the project repository.
2. Open the project in the development environment.
3. Open the required HTML files using the Live Server.
4. Launch the application on port 5500.
5. Use the navigation menu to access the different pages.

## Notes

This project is developed as a Medical Appointment Booking website for the frontend capstone project.
